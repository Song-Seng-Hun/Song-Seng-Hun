### 물리에서 출발해 로봇과 비전 AI를 거쳐, 지금은 AI 팀과 함께 게임을 만들고 있습니다.

여러 AI 에이전트가 기억을 나누며 함께 일하는 작업 환경을 설계하고 운영합니다. AI에게 없는 감각(눈과 귀)을 도구로 붙여 주고, 그 팀과 작은 게임을 만드는 중입니다.

<sub>From physics through robots and vision AI — now running a team of AI agents and building a small game with it.</sub>

| | 지역 | 한 일 |
|:-:|---|---|
| 01 | 물리 연구소 | 물리학 학사, 양자광학 대학원 과정 (NV센터 다이아몬드 온도 센싱 시뮬레이션) |
| 02 | 로봇 공방 | ROS AMR 이동 명령 연동, 로봇팔 gRPC 통신 시험, Qt FK/IK 시뮬레이션 · [dobot](https://github.com/Song-Seng-Hun/dobot): YOLO로 블록의 색과 모양을 인식하는 로봇팔 · [my_custom_stt_train](https://github.com/Song-Seng-Hun/my_custom_stt_train): 한국어 음성인식 학습 환경 |
| 03 | 비전 데이터 공장 | 약 2년간 이미지 분류 모델(EfficientNet) 학습과 운영, 데이터 검수와 정제, Streamlit 검수 도구, YOLO 초벌 라벨링 파이프라인 |
| 04 | 감각 연구소 | AI가 영상과 음악을 읽을 수 있게 하는 분석 도구 (비공개) |
| 05 | AI 팀 본부 | 여러 AI가 기억을 공유하며 협업하는 작업 환경 (비공개) |
| 06 | 게임 마을 ☁️ | 그 팀과 함께 만드는 작은 게임, *to be continued* |

**다뤄 본 것** Python · C++ · PyTorch · OpenCV · YOLO · EfficientNet · ROS · gRPC · FastAPI · Streamlit · Qt · Label Studio<br>
**그리는 도구** Clip Studio Paint · After Effects · Reaper
